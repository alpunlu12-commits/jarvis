# JARVIS V4

Bilgisayarında konuşarak iş yaptırdığın ücretsiz sesli asistan. Google Gemini Live ile çalışır; kendi ücretsiz Gemini API
anahtarınla kullanırsın. macOS 14+ (Apple silicon) ve Windows 10/11.

## İndir

**[Son sürümü indir →](https://github.com/alpunlu12-commits/jarvis/releases/latest)**

- **Mac:** `JARVIS-<sürüm>.dmg` dosyasını aç, JARVIS'i Uygulamalar klasörüne sürükle.
- **Windows:** `JARVIS-<sürüm>-Windows-Setup.exe` dosyasını çalıştır. Mavi uyarı çıkarsa: **Ek bilgi › Yine de çalıştır**.

JARVIS kuruluysa yeni sürümleri kendisi bulur: **Ayarlar › HAKKINDA › GÜNCELLE**.

## Başlarken

1. JARVIS'i kur ve aç.
2. Ücretsiz Gemini API anahtarını al ve yapıştır: [anahtar nasıl alınır (video)](https://youtu.be/VZl5uBT4a60)
3. Konuşmaya başla.
